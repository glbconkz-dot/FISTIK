# Sketch project (ЭП)

Minimum album:

- Site / GP diagram
- Typical floor plans, elevations, one section
- TEP table
- 3D views (optional but expected by this studio)
- Explanatory note at sketch depth (not full PZ)

Check against APZ setbacks and height.
Flag missing engineering surveys — they block later expertise even if
the sketch looks finished.

Hand to working-project only when TZ, GP, and AR sketch are at least `draft`.
Delegate `architecture` for composition comments. Do not pretend KR/MEP
working sets exist at this stage.
