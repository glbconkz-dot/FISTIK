# Expertise gate

Call `expertise_gate`. The boolean it returns is the answer.

Typical expert comments this studio trains on (Kazakhstan):

- APZ vs actual setbacks / height / function
- Missing or expired engineering surveys
- Fire path, compartmentation, and PB vs AR mismatch
- KR without load cases / soil data
- MEP without TU from networks
- SM volumes not matching AR
- MGN routes not shown on plans
- POS that ignores site logistics

Do not claim a positive expert conclusion. Only the expertise body issues that.
Your job is: package complete, internally reviewed, typical holes closed.
