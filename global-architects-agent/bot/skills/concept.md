# Concept project

Goal: lock the brief so sketch (ЭП) can start without rework.

Collect, in this order:

1. Client, site (cadastre if known), typology, floors, approx. area
2. APZ / planning constraints the client already has
3. Program: dwelling mix, production flow, bed count, parking
4. TEP targets (building area, density, height)
5. Which later expertise sections this typology will force (hospital ≠ warehouse)

Do not draft working-project stamps at this stage.
Output a one-page TZ: purpose, site, program, TEP, risks, next department.
If the user names a catalog project, call `project_status` first.
